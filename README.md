# BU Foundations Bootcamp

A central repository for coursework, practice exercises, and foundational projects completed during the Boston University Master's prep bootcamp. Designed to refresh core software engineering principles and introduce essential data science concepts ahead of graduate-level study.

## 📌 Overview
* **Program:** Boston University Master's Preparation
* **Focus:** Software engineering fundamentals, object-oriented design, algorithmic problem solving, and data science essentials.
* **Goal:** Build a solid technical foundation for advanced graduate coursework.

## 🛠 Tech Stack & Tools
* **Software Engineering:** Object-Oriented Programming (OOP), Data Structures & Algorithms, Code Architecture
* **Data Science:** Data Analysis, Statistical Concepts, and Data Manipulation 
* **Development Environment:** Git/GitHub, IDEs, Command Line Interfaces

### Repository Layout
- `/modules` – Topic-by-topic coursework and exercises
